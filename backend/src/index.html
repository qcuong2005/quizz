🟡 Ví dụ đồng bộ (server-side PHP – mô phỏng)

Trong lập trình đồng bộ, server sẽ tải RSS xong rồi mới gửi nội dung cho client.


<?php
$rss = simplexml_load_file("https://vnexpress.net/rss/tin-moi-nhat.rss");
foreach ($rss->channel->item as $item) {
  echo "<li><a href='{$item->link}'>{$item->title}</a></li>";
}
?>

Đây là ví dụ để hiểu logic đồng bộ. Để chạy thật cần đặt trong server hỗ trợ PHP (XAMPP, v.v.)
